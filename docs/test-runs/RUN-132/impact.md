# 发布候选集成影响清单

发现并游玩新游戏：商店在一念长生与一克之差之间加入此生，旧十八款相对顺序保持。
游玩与存档：航司使用指定冻结成品，此生使用已修复大存档的冻结成品，宿主保存实现保持d14f12a。
