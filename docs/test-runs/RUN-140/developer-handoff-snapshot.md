## 修改
1. 客流推荐新增/增派飞机按100小时飞行上限、168小时含周转占用、基地时刻、经停、实际周排班求可执行最大往返数；不再固定1–7班。每批至多20架，只增派真正空闲飞机，保留应急备用和当周检修代飞。
2. 每个候选市场比较8档票价，统一调整本公司该机场对全部配机票价。评分考虑本地客流、竞争吸引力、转机供给；目标为旅客行程增长，允许现金预算内短期让利。最终执行前用与周结算相同的自动检修/代飞/整网客流预测复核；需求不要求先存在供给缺口。
3. 显示新增独立旅客行程、转机行程、竞争市场客流净转入、周贡献变化、一次费用、四周让利预算。独立旅客行程不把中转乘客的两段乘机重复计为两位旅客。原班次及配机保留，同市场票价更新；新的 trafficPrice 标记避免被利润优先自动定价覆盖，手动改价可解除。
4. 手动新增/增派在进入报价步骤时默认排满并推荐整线客流票价；提供“排满可用航时”按钮，可手改频次/票价。保存后同线全部配机统一票价，编辑旧计划不擅自填满。支持每周最多100次往返，仍受飞行、周转及冲突限制。
5. 汰换详情/退役弹窗优先列出可立即接续的空闲机。同基地、宽窄体同级、足够航程、维护状态、较新机龄、原舱位和时刻均验证；跳过应急备用、其他飞机的检修代飞、未交付、召回及关联汰换订单飞机。确认后结清旧机抵押、改舱及出售/退租，沿用原配机计划，不新购飞机。旧手动时刻不可兼容则不提供该候选。
6. 排班验证只计算与当前飞机共享机场对/经停航段的连通机群，保留这些飞机所有航线和基地原始起飞波次上下文；不再每次二分试班都排整个机队。
