### 独立弹窗与工作区

`modals.json` 覆盖57个可达状态×5尺寸：我菜单、存档、玩家列表、重开确认、指南及翻页、自动分红、招聘管理四子页及翻页、人员调店/晋升、预算、手动策略、门店/地区/个人业绩及分页、店铺机会、重组机会列表、集团协同、行业细分、对手动态、经营账单、商战复盘及分页、HR初始页、季度KPI、对手详情、联盟/收购表单、竞争策略、新建公司、扩建/分店/招聘、个人增资/分红/贷款/还款/融资/上市/重组表单。

`extras.json` 再覆盖19个条件状态×5尺寸：HR托管/历史、聘请人事经理、相关管理子页、证券买入、榜单资料、国际对手、真实建立业务后的账单/扩产/撤出确认、手动存档后的删除确认及返回槽页。

每个页面扫描启用控件：真实滚入视野、elementFromPoint命中、所有hidden/clip祖先永久裁剪、纵向兄弟box交叠、文本Range横向越界。截图保留每个状态。控件命中检查不是仅检查页面横向宽度。

`company-sellCompany` 是检查脚本先验枚举的不存在动作，五尺寸均无法定位。当前UI没有该data-type；不计成通过状态，也不计成真实坏按钮。已有出售/重组显示逻辑应以实际UI为准。

## 检查边界

这次是UI独立验收，不重新做长期经济平衡。自然旧档未触发的具体破产接管报价、剧情邮件/交割谈判、已成交战略持仓转让，不冒充本轮实际点过；它们属于条件页面清单，需结合实现方既有专项证据。通用容器、长文本、确认按钮和同类表单已覆盖。

所有截图来自隔离浏览器；没有覆盖玩家已有档案，没有发布或修改平台。
