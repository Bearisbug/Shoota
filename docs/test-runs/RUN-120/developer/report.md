# 经营提醒优先级与推进提速验收

日期：2026-10-26。范围仅为经营消息排序、运行清单合并及计算提速；没有调整经营数值、延误概率、口碑规则、航线规则或机场目录。使用 web-game-responsive 实现/修复模式。

## 问题与修改

旧版 `finishOperating` 无条件优先打开 operationsModal，排名/交付只进入顾问待看列表；advisor 又按数值 priority 把延误104排在发展消息98前。`before-tests.txt` 留存修复前三项失败。现在所有简报来源使用同一发展优先顺序：排名突破→飞机交付→基地/联程/竞争动态→运行报告与经营建议。结束经营直接展示首条发展动态，多周 operations 合并一个入口；关闭首条仅标记首条，未展示的交付、其他发展动态、运行报告仍保留。需要用户选择的剧情/退役及破产/存档异常继续走原处理流程。

性能剖析发现反复线性搜索1040机场、为排行榜生成151家航司的完整竞争航线明细、排班冲突搜索遍历全机队。修改为机场索引、排行榜/客流只取所需档案字段、按方向机场对索引冲突检查。开始快进只更新进度操作区，不再先整页重算一次排班。每周仍独立结算并保存，不跳过自动保障、财务、事件或成长。
