## 八项改动范围

1. 融资、偿还均支持自定义金额（万元）与填入全部可借/可还；保留原额度、利率、资产规则。
2. 总览地图支持拖动、缩放、查看全部；缩小时隐藏碰撞地名并优先保留基地；双指逻辑已实现但真机未验收。
3. 顾问待办逐条完成；仅移除当前已阅或完成操作的事项，其他事项持久保留。
4. 联程通知来自已经开通、实际结算的连接客流，至少间隔八周；航网扩张预测不再主动弹窗。
5. 日常定价与延误不主动弹窗；自动定价由玩家主动开启、默认关闭。增加基地开发、丝路合作、运动会、会议与城市影响力情景，影响实际需求。
6. 首次超越其他航司产生合并里程碑通知，避免来回超越重复打扰。
7. 国际资质新增十条不同的在营国内航线条件；保留原口碑/飞机要求，已有资质和审批保留。
8. 全体航司同一评分公式：口碑27%、机队12%、覆盖机场12%、航线密度12%、服务20%、可靠性12%、盈利5%。机队/覆盖/密度随当前榜单最高值按比例归一化，不再按固定规模封顶；密度按平均每条不同航线的周往返频次计。

## 验收中修复的缺陷

### TC-095 可引用：全额还款残留一万元

- 修复前成品：5821d1fcedd7216010283c85286db4d67e0f6c919aaedacdc094b7cf4a487753。
- 复现：借入31,234万元 → 偿还 → 填入全部可还。浮点数向下取整把金额填为31,233万元，偿还后剩余1.0万元负债。
- 修复：引擎统一计算以万元为单位的可借/可还金额，消除浮点边界误差；借还后负债按同一单位规整，UI调用统一金额。
- 复测：同样借31,234万元，全部可还准确填31,234万元，确认后负债为零；桌面双击借款确认只入账一次。
- 前证据：[defect-full-repayment-remainder-before.png](platform/defect-full-repayment-remainder-before.png)。后证据：[defect-full-repayment-remainder-after.png](platform/defect-full-repayment-remainder-after.png)。回归用例名为 `source defect: full repayment does not leave a ten-thousand-yuan floating-point remainder`。
