# 配机入口与同航路竞争：2026-10-28

状态：本地开发完成，未部署；最终构建指纹见同版本 manifest.json。

## 修改
- 飞机选择恢复到开航第一步，第三步共用同一字段；空闲机优先，显示已用航时。手动选机后换目的地不擅自换机；换基地重新选择。无可用飞机显示原因。
- 竞争激烈、供给充足或预估亏损时，报价页可展开降价/增派比较、空闲飞机数量与收益风险。使用航路真实总班次及加权票价。吸引力份额明确不是实际销量，仍受座位、需求、排班与资金限制。
- 同航路显示每家对手周客流、份额和相比无玩家参与基准的流失；客流榜显示较上周变化与竞争净分流。旅客池按实际承运分配，玩家吸引的客流同步从对手扣减；对手也可能吸收其他退出者的客流。
- 持续超过35%份额逐渐累积竞争收缩，目标值为(份额-35%)/55%，限制在0–1，每周15%平滑。收缩超过80%时较弱的第4–8个对手退出本航路，前3家继续竞争；份额回落可重返。不是整家航司破产。退出新闻沿用8周冷却。
- 仍按市场汇总，不模拟NPC逐架/逐班运行。原客流模型保留，对手收缩最多提高15%竞争需求系数；不保证降价增班盈利。
