## 修改与复现
1. 原增长推荐只在前 36 个热门目的地中查航程，C909 在杭州、乌鲁木齐、罗马等基地可全部落空；改为逐个检查可达目的地，找到可行市场才占用候选名额。
2. 原增班直接尝试最大周频次，忽略少量增班。现比较每周 1–7 次往返，并选择收益更合适的频次。测试 HGH–CAN 两架 A380，原方案空结果，新方案用空闲第二架加 1 次，原配机仍 1 次；全网预测净增 535 人次、周贡献约 4.2 万。
3. 候选计入自动定价，本地需求不再错误扣掉转机旅客；整批净增长不通过时按半批重试。最终仍须同时通过净客流、净贡献、检修、备用机、航程、时刻与现金条件。没有闲置飞机时不向忙碌飞机追加任务。
4. 机库及基地时刻扩建输入批数，显示递增总费用、新增/总容量和维修固定支出。批量价格等于逐次价格总和；非法值、资金不足不扣款。未新增人为批数上限。
5. 周结算重用未变化的联程几何模板、按 ID 查找飞机和航线；检修和其他不影响评分的操作不重复算全球榜。缓存最多两套几何，不缓存当周客流、票价或竞争结果。无推荐时跳过无用的全网排班与二次预测，同类型无收益空闲机不重复搜索。
