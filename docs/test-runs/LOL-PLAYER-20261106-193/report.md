规则验证：新旧预算差异、成绩/明星贡献、查询无副作用、季末结算幂等、跨季结转、新人报价、旧档迁移、负债限制；三个故障注入用例证明恢复旧预算/取消新人折扣/取消结算保护时对应断言失败；三路线两赛季、冒泡赛、阵容建议、出售撤回、历史榜单、市场和教练合同回归。实际日志见 rules.json 与对应 *.log。
