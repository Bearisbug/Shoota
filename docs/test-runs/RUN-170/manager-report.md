日期：2026-10-30。源码：`public/games/lol.html`。SHA256：`0258d860d8be31550b084b7fed19ba7818ca4d6e27274a800d613a28ad3ba68c`，3,096,940字节。当前回归版本、独立8778验收宿主与交付HTML相同。未部署线上，未操作用户原有游戏标签或存档。

## 本次变化

- 年度正赛规则移植自选手版：2014/2015的LPL四强/八强、2016—2020八队冒泡、2021—2024十队冒泡且四强双败，2025起按选手版八队双败；2014夏季四队双败为历史特例。LCK同时按年代切换八强单败、阶梯、六队单败及分段双败。
- MSI在2014不举办、2020取消；2015单循环、2016—2022双循环后四强单败，2023起八队双败。世界赛2023之前四组双循环、小组前二进入八强，2023起瑞士轮，八强起单败。
- 右上角为范围选择（1场、5场、到本赛段结束）及推进按钮。完整系列赛计场；常规/季后、MSI循环/淘汰、世界赛小组或瑞士/淘汰边界停止。没有本队比赛时推进当前阶段，下一阶段比赛保留。半场比赛继续已有比分与战术，结算不重复。
- 选手详情四个页签，加入开局前的真实战队/赛事统计、来源和荣誉。本档按实际出场战队分别统计，转会记录独立保存。真实未来荣誉不会随着游戏推进自动加入。
- 20名90+只限制初始能力，后续保存、载入、成长不再按人数压到89。借用选手版的16经验、年度成长预算、顶级减速、赛季复评和退役逻辑；保留17—23岁完整成长。替补训练可增长，上场更快，核心表现/强敌有加成。差赛季回落，潜力保留。普通98、真人Faker99、仅用户招募传奇100规则不变。

## 验证

`node scripts/test-lol-alignment.cjs`：10套件565断言通过，`all-tests.json`保存每套原始输出及构建指纹。包含2014—2026全部13个年度完整比赛结算、2014/2016/2021/2023/2027五个代表年份重复全季、2027—2029连续三个赛季。全部真实比赛引擎执行，无伪造赛果替代。

## 存档与重建

旧存档保留已经生成的签表、已赛比分与本季旧编号；新生成赛事使用年度规则，下赛季采用新赛历。旧档总计无法可靠拆分到某队的记录标为未拆分，不转嫁现队。旧版已经扣除的能力不凭旧峰值直接返还，后续正常成长。

可离线执行：`python3 scripts/build-lol-history.py`、`python3 scripts/build-lol-alignment.py`。重建后字节与指纹不变，见`build-check.json`。`build-lol-final.py`导出单文件。规则与UI扫描通过；设计文档检查无新增错误；测试文档保留存量格式警告，本轮用例与轮次已登记。

完整冻结、离线ZIP与工作区根HTML的路径和哈希见`handoff.json`。不覆盖上一次冻结，不含线上部署操作。
