# v1.6.1 合同决策修复交付

2026-10-30。此版在 v1.6.0 的分轮自由市场上修复移动端合同流程；未部署，也未修改经理版和平台源码。

## 修改与原因

- 原「处理合同」只定位到合同长页顶部，平台 390×844 内接受续约按钮在 iframe y≈2005，必需签约需要长页滚动。
- 现在顶部操作直接打开既有 player-sheet 弹层；一页一份报价，战队、年薪、年限、定位、同位置竞争、买断费（如有）在正文；关闭、合同翻页、接受操作固定可达。
- 合同页先展示个人签约入口，再展示市场、队友去向和引援建议。签约完成后弹层直接提供「开始新赛季」。重复接受无效，不再对失败的重复请求显示签约成功。
- 沿用经理版配色、队徽、字号和弹层组件，手机竖屏底部两行操作，矮横屏正文改两列；未缩放整页或减少必要条款。
- 能力／潜力没有改动。经理基线校验改为明确固定历史 HTML：`assets/reference/lol-manager-a6ebc4b0.html`，来源与指纹见 `assets/history/manager-reference.json`；不再依赖会继续更新的经理工作文件。
