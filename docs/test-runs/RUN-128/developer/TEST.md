3. 真机 iOS Safari、Android Chrome、系统软键盘、安全区、200%文字放大待人工；桌面视口模拟不能替代。
4. 未部署测试站/正式站，未验证远端成品、最终封面。平台截图使用独立临时副本和临时山水封面。
