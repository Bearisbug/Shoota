## 行为修复

平台收到游戏存档消息后同步留下本机恢复记录，随后按玩家和游戏串行写入 IndexedDB。只有事务完成才显示“已存档”；事务进行中、失败但有恢复记录、两种存储都不可用分别显示明确状态。失败可以点击或键盘重试，重试区域为 44 像素且不增加顶栏高度。

保存队列使用独立快照；旧事务不会清除新恢复记录。立即刷新优先恢复待提交数据，切换游戏后旧回调不会改新游戏提示。备份导出包含待提交进度，恢复按顺序写入；失败不会假报成功。无变化的消息不会伪造新保存时间。

保持原游戏存档字典、玩家/游戏键、桥消息、iframe sandbox 以及 CJ0/CJ1 存档码兼容。新增 `changju.pending.v1:` 命名空间仅存储本机恢复记录，不新增云端公开数据。
