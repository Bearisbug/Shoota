## 2. 测试范围 / 不测什么

- 覆盖：匿名统计的上报与落库、看板登录与锁定、看板五块数据的口径与页态，接口层与页面层都测。
- 覆盖：新游戏上架、斗罗换版，以及游玩时的存档提示与外部链接。
- 覆盖：http 下的存档与旅客编号搬到 https，老玩家不算新旅客。
- 覆盖：手机竖着打开游戏时平台不转横，薯光用自带的横屏提示。
- 不测：

| 不测项 | 归属 |
| --- | --- |
| 商店、游戏、存档码等平台已有功能的冒烟 | `docs/LAUNCH.md` 第 5 节的最小冒烟集 |
| 各款游戏自身的玩法 | 游戏作者，无归属的部分为已知风险 |
| 单元 / 集成自动化 | 无，本仓没有自动化测试套件 |
| 性能压测、免费额度用量 | 无归属——已知风险，上线后按设计文档 §21 每周看面板 |
| 安全渗透 | 无归属——已知风险，见设计文档 §28 |

## 3. 环境与前置

- 环境：

| 环境 | 入口 | 就绪判定 | 测试账号 | 种子与重置 | 外部副作用 |
| --- | --- | --- | --- | --- | --- |
| 本地 | http://localhost:8791 | 首页标题含「shoota 游戏平台」，`/kanban` 返回的页面标题含「shoota 看板」 | 看板密码见下方测试账号表 | 可跑 | 无，数据只进本地 D1 |
| 预发 | 无——项目只有本地与线上两套环境 | — | — | — | — |
| 线上 | https://shoota.ai | 首页标题含「shoota 游戏平台」，`/kanban` 返回的页面标题含「shoota 看板」 | 看板密码：Bitwarden `SHOOTA_KANBAN_PASSWORD`；测试旅客：每轮新开一个无痕浏览器，记下它的旅客编号 | 禁跑 | 真实：测试旅客的行写进线上统计，用例后置按旅客编号删除 |

- 启动(本地)：在项目根依次执行
  - `printf 'KANBAN_PASSWORD=local-test-pass\nKANBAN_SECRET=local-secret-for-tests\n' > .dev.vars`（文件已在 `.gitignore`）
  - `npx -y wrangler@4.151.1 d1 migrations apply shoota-metrics --local`
  - `npx -y wrangler@4.151.1 dev --port 8791`
- 测试账号(本地)：

| 角色 | 账号 | 获取方式 |
| --- | --- | --- |
| 看板查看人 | 密码 `local-test-pass` | 启动步骤写进 `.dev.vars` |
| 旅客 | 每条用例新开一个浏览器配置目录 | 首次打开平台时自动生成旅客编号，在浏览器控制台读 `JSON.parse(localStorage['changju.meta.v1']).vid` |

- 种子数据与重置(本地)：
  - 清空统计：`npx -y wrangler@4.151.1 d1 execute shoota-metrics --local --command "DELETE FROM visitors; DELETE FROM visitor_days; DELETE FROM game_days; DELETE FROM login_guards;"`
  - 看板口径种子：`npx -y wrangler@4.151.1 d1 execute shoota-metrics --local --file scripts/seed-local.sql`，日期按执行当天的北京日期往前推，内容见文件注释
  - 查数据：`npx -y wrangler@4.151.1 d1 execute shoota-metrics --local --command "<SQL>"`
  - 锁定到期：把 `login_guards.locked_until` 改成 0，代替等 15 分钟
- 工具：Edge 浏览器（Playwright 驱动，每条用例独立的配置目录）、curl、wrangler d1 execute。线上直接请求接口时用 curl 或浏览器，Python 默认 User-Agent 会被 Cloudflare 浏览器完整性检查拦下，返回 403 与错误码 1010。
- 模拟 http 与 https 两个地址（TC-027～TC-029）：Playwright 把 `http://shoota.ai/*` 与 `https://shoota.ai/*` 的请求都转给 http://localhost:8791。浏览器里它们仍是两个来源，各有一份本地存储，与线上一样。浏览器启动时加 `--no-proxy-server` 与 `--host-resolver-rules=MAP shoota.ai 127.0.0.1`，没被转走的请求连不到线上。
- Playwright 启动 Chromium 系浏览器时默认关掉 `HttpsUpgrades`，模拟的是不自动升级 https 的浏览器（存档会留在 http 下的那类）。
- 模拟手机（TC-047）：Playwright 新建上下文时设 `viewport` 390×844、`isMobile: true`、`hasTouch: true`，页面的 `(pointer: coarse)` 为真；`userAgent` 设成 iPhone Safari 的标识（薯光按它判断是不是手机，不设就不出自带的横屏提示）；横着拿改设 844×390。电脑用 1280×800、不开触屏。
- 模拟卡住（TC-043、TC-044）：游戏文件请求一直不回应用 Playwright `context.route` 收下请求后不处理；存档库没回应用 `addInitScript` 把平台页面的 `indexedDB.open` 换成永不回调的空请求；限速用 CDP `Network.emulateNetworkConditions`。
- 证据目录：`docs/test-runs/`

## 5. 回归策略

- **全量轮**：首次成稿、看板或上报接口改版、数据表结构变更。
